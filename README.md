# Coparentalité

Application web perso de coparentalité : garde alternée, vacances scolaires, dépenses partagées 50/50 et fiches enfants.

- Une seule page (`index.html`), sans dépendance.
- Données stockées sur le téléphone, synchronisées entre les deux parents via un Google Sheet (`apps-script/Code.gs`).
- Publiée avec GitHub Pages.
